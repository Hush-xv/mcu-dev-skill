# ARM Cortex-M 评审清单

配合 `embedded-workflow` 阶段 4 使用。逐类核查，分级 Critical / High / Medium，报告后默认输出**最小可应用 diff**；仅单文件示例或用户明确要求完整替换时才输出完整文件。

## 1. 时钟与等待周期

- [ ] PLL 配置产生的实际频率 = 预期频率（输入/VCO/输出范围全部核对）
- [ ] Flash 等待周期（FLASH_ACR.LATENCY）与 HCLK 匹配；**先提频后加等待周期，先降等待周期后降频**
- [ ] 各总线（AHB/APB1/APB2）分频后不超过各自上限
- [ ] HSE/PLL 就绪标志带超时检测后才切换系统时钟
- [ ] 时钟切换后 SWS 标志确认切换完成
- [ ] 高端型号（F4/F7/H7）稳压器档位与超频 Over-drive 模式

## 2. 初始化顺序

- [ ] 外设时钟使能先于任何寄存器访问（否则总线错误）
- [ ] GPIO 配置（含 AF 复用号）先于外设使能
- [ ] NVIC 配置在外设就绪之后
- [ ] DMA 配置先于外设的 DMA 请求使能位
- [ ] 外设使能位是初始化序列最后一步

## 3. 中断

- [ ] 优先级分组只在启动时设置一次
- [ ] 所有优先级在 `__NVIC_PRIO_BITS` 有效范围内
- [ ] **FreeRTOS 边界**：调用 FreeRTOS API 的 ISR 优先级 ≥ `configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY`（数值上更低优先）
- [ ] 每个使能的中断都有处理函数；共享向量处理所有可能的标志源
- [ ] 使能中断前先清 pending 标志（否则一使能就触发）
- [ ] ISR 内无阻塞操作（延时、printf、互斥量）

## 4. DMA

- [ ] 流/通道与外设的映射对照参考手册 DMA 请求表核对（不猜）
- [ ] 两个外设不共用同一 DMA 流
- [ ] 缓冲区在可 DMA 的 RAM：**不在 CCM（F3/F4）、不在 DTCM（F7）**——放错位置传输静默失败
- [ ] 缓冲区对齐（字传输 4 字节对齐）
- [ ] 方向、外设/内存数据宽度、增量模式三者都核对
- [ ] 新传输开始前清除传输完成标志
- [ ] FIFO 阈值与突发长度兼容；循环模式检查缓冲区覆盖
- [ ] 带 D-Cache 的型号（F7/H7）对 DMA 缓冲区做 Cache 维护

## 5. 内存与 volatile

- [ ] `volatile`：硬件寄存器指针、ISR 与主循环共享变量，全部加上（只解决可见性，不保证原子性——按访问宽度与并发场景补临界区/原子操作）
- [ ] SCB/NVIC 寄存器写入后加 `__DSB()` / `__ISB()` 屏障
- [ ] 链接脚本栈空间 ≥ 最坏调用深度 + ISR 嵌套；ISR 内不开大局部数组
- [ ] 读改写用 `|=` / `&= ~`，保留位不破坏；状态标志清除方式按外设规定（读清 / 写 1 清）

## 6. FreeRTOS（如使用）

- [ ] HAL 时基不用 SysTick（换 TIM6/7 等空闲定时器）
- [ ] ISR 内只用 `*FromISR()` 变体，唤醒更高优先级任务后调 `portYIELD_FROM_ISR()`
- [ ] `configPRIO_BITS` 与芯片 `__NVIC_PRIO_BITS` 一致
- [ ] 任务栈用 `uxTaskGetStackHighWaterMark` 验证过；开发期开 `configCHECK_FOR_STACK_OVERFLOW`

## 7. GPIO 特别项

- [ ] 复用号（AF0-AF15）对照数据手册复用表逐脚核对
- [ ] **SWD 引脚（通常 PA13/PA14）未被误配为其它复用**——配错可能导致调试器无法连接；按型号尝试 Connect-Under-Reset（NRST 复位下连接）或该型号支持的恢复引导方式（见 ST AN4989/AN2606），能否走系统 bootloader 依器件与引脚复用而定
- [ ] I2C 引脚开漏 + 上拉；未用引脚配模拟输入省电

## 8. 安全

- [ ] 读保护（RDP）级别与部署阶段匹配；量产关调试口
- [ ] 看门狗已启用且喂狗路径无死区
- [ ] Flash 中无硬编码密钥；敏感扇区考虑 PCROP

## 症状 → 常见原因 → 验证与修法（Top 15，按出现频率排序）

| 症状 | 常见原因 | 验证与修法 |
|---|---|---|
| 首次访问外设寄存器即出错/挂死 | 漏开外设时钟（表现依型号：总线错误/读零/写入无效） | 验证：核对 RCC 使能位；修法：时钟使能先于任何寄存器访问 |
| 外设完全无输出、引脚无波形 | AF 复用号错 | 验证：数据手册复用表逐脚核对；修法：改正 AF 号 |
| 串口打印乱码/收发异常 | 波特率用错总线时钟（APB1/APB2 混淆）或 `HSE_VALUE` 定义不符 | 验证：打印实际外设时钟并与预期比对；修法：重算 BRR、核对 `-DHSE_VALUE` |
| 串口完全无输出（printf 不打印） | printf 未重定向到该 UART（`fputc`/`_write`），或外设/GPIO 时钟未配 | 验证：检查重定向实现与初始化顺序；修法：补重定向、先配时钟 |
| 高频下随机 HardFault | Flash 等待周期不足 | 验证：HCLK 对照等待周期表；修法：按表设 LATENCY，先提频后加等待 |
| DMA 传输静默失败/数据全 0 | 缓冲区在 CCM/DTCM（不可 DMA） | 验证：链接脚本查看缓冲区所在段；修法：移入主 SRAM 并 4 字节对齐 |
| 优化后 ISR 读到的总是旧值 | ISR 共享变量缺 volatile | 验证：反汇编确认读取被优化外提；修法：加 volatile，必要时加屏障 |
| SPI 完全不通 | CPOL/CPHA 与从机不符 | 验证：逻辑分析仪比对时钟相位；修法：按从机手册改模式 0~3 |
| 调用 FromISR 即硬错误 | ISR 优先级越过 FreeRTOS 边界 | 验证：核对优先级数值与 `configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY`；修法：调至边界内 |
| 一个外设的 DMA 无故失效 | 两外设共用同一 DMA 流 | 验证：列出全部 DMA 分配；修法：重映射通道或改轮询 |
| SWD 突然连不上芯片 | PA13/PA14 被重配为其它复用 | 验证：检查最近 GPIO 配置改动；修法：Connect-Under-Reset 恢复（依型号），代码禁配 SWD 引脚 |
| 程序在 ISR 里卡死 | ISR 内调 HAL_Delay | 验证：检查 ISR 调用链；修法：延时移出 ISR，用标志位+主循环 |
| 定时周期偏差大 | PSC/ARR off-by-one（都 +1 生效） | 验证：公式手算对照实际周期；修法：重算，核对定时器时钟 ×2 规则 |
| 一使能中断就立刻进 ISR | 未清 pending 就使能 | 验证：使能前读状态寄存器；修法：先清标志再 NVIC_EnableIRQ |
| 偶发数据错乱难复现 | ISR 与主循环读改写同一寄存器/变量 | 验证：梳理共享资源访问路径；修法：关中断临界区或原子操作 |
| 优先级行为与预期不符 | 优先级分组被多次设置 | 验证：搜索全部分组设置调用；修法：启动时设一次 |
