# ARM Cortex-M 评审清单

配合 `embedded-workflow` 阶段 4 使用。按问题范围裁剪：窄问题只核查相关类目并说明范围；用户要求全面评审或改动跨类目时才逐类核查。发现按 `embedded-workflow` 的统一证据和严重度规则报告，不为风格偏好定级。修复默认输出**最小可应用 diff**；仅单文件示例或用户明确要求完整替换时才输出完整文件。

**适用范围标注**：标【STM32/GD32】等前缀的项仅适用对应平台；其余为 Cortex-M 通用检查。RP2040（XIP 外置 Flash）、nRF 等平台遇到不适用项时，按其手册确认对应概念，不照单全查。

## 1. 时钟与等待周期

- [ ] Flash 等待周期与 HCLK 匹配，**顺序不可反**：升频**先增加等待周期再切换高频**，降频先切低频再减等待周期（寄存器按厂商查手册：【STM32】FLASH_ACR.LATENCY；【GD32】按具体系列查 FMC 等待周期寄存器，如 FMC_WS.WSCNT；按器件、供电电压核对；RP2040 等外置 QSPI/XIP Flash 平台无此项，按平台手册确认）
- [ ] 【STM32/GD32】PLL 配置产生的实际频率 = 预期频率（输入/VCO/输出范围全部核对）
- [ ] 【STM32/GD32】各总线（AHB/APB1/APB2）分频后不超过各自上限
- [ ] HSE/PLL 就绪标志带超时检测后才切换系统时钟（就绪标志按平台确认）
- [ ] 【STM32/GD32】时钟切换后 SWS 标志确认切换完成
- [ ] 【STM32/GD32】高端型号（F4/F7/H7）稳压器档位与超频 Over-drive 模式

## 2. 初始化顺序

- [ ] 外设时钟使能先于任何寄存器访问（后果依型号而异：总线错误/读零/写入无效——与主工作流阶段 3 口径一致）
- [ ] GPIO 配置（【STM32/GD32】AF 复用号；其它平台按其引脚复用机制，如 RP2040 的 GPIO 功能选择）先于外设使能
- [ ] NVIC 配置在外设就绪之后
- [ ] DMA 配置先于外设的 DMA 请求使能位
- [ ] 外设使能位是初始化序列最后一步

## 3. 中断

- [ ] 优先级分组只在启动时设置一次
- [ ] 所有优先级在 `__NVIC_PRIO_BITS` 有效范围内
- [ ] **FreeRTOS 边界**：调用 FreeRTOS API 的 ISR 不得比 port 允许的 syscall 边界更高优先级；先检查项目实际定义的阈值宏与表示方式——`configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY` 通常是未移位的库优先级，`configMAX_SYSCALL_INTERRUPT_PRIORITY` 通常是写入 NVIC 的移位值，不能混用比较。使用 CMSIS `NVIC_SetPriority()` 时按其接口要求传未移位逻辑优先级；比较方向按 Cortex-M 数值越大、紧急度越低解释
- [ ] 每个使能的中断都有处理函数；共享向量处理所有可能的标志源
- [ ] 使能中断前先清 pending 标志（否则一使能就触发）
- [ ] ISR 内无阻塞操作（延时、printf、互斥量）

## 4. DMA

- [ ] 【STM32/GD32 F4 系】DMA 流/通道映射对照参考手册请求表核对；其它平台按各自的 DMA 通道/请求机制核对（不猜）
- [ ] 【STM32/GD32】两个外设不共用同一 DMA 流；其它平台核对其 DMA 控制器的通道、请求源与共享限制
- [ ] 【STM32/GD32】缓冲区不在 CCM（F3/F4）/DTCM（F7）；其它平台核对其可 DMA 内存区域——放错位置传输静默失败
- [ ] 缓冲区对齐（字传输 4 字节对齐）
- [ ] 方向、外设/内存数据宽度、增量模式三者都核对
- [ ] 新传输开始前清除传输完成标志
- [ ] 若控制器支持 FIFO/突发传输，核对阈值与突发长度兼容性；循环模式检查缓冲区覆盖
- [ ] 所有带 D-Cache 的型号（如 F7/H7，是否带 D-Cache 按器件手册确认）对 DMA 缓冲区做 Cache 维护

## 5. 内存与 volatile

- [ ] 按编译器/ABI 判断硬件寄存器及 ISR 异步共享对象是否需要 `volatile` 保证实际读写；它不提供原子性或任务同步，按访问宽度和并发关系补临界区、原子操作或 RTOS 同步原语
- [ ] 仅在架构、CMSIS 或器件文档要求的系统控制操作后使用 `__DSB()` / `__ISB()`；按操作要求选择屏障类型与位置，不在每次 SCB/NVIC 写入后机械添加
- [ ] 链接脚本栈空间 ≥ 最坏调用深度 + ISR 嵌套；ISR 内不开大局部数组
- [ ] 读改写用 `|=` / `&= ~`，保留位不破坏；状态标志清除方式按外设规定（读清 / 写 1 清）

## 6. FreeRTOS（如使用）

- [ ] 【STM32 HAL + RTOS】优先评估用独立定时器作为 HAL 时基，避免与 RTOS 共用 SysTick 时的 tick/优先级冲突；若保留 SysTick，核对 HAL tick 与 RTOS tick 的处理、优先级及 ISR 调用约束（符合 HAL 编程模型时可共用）
- [ ] ISR 内只用 `*FromISR()` 变体，唤醒更高优先级任务后调 `portYIELD_FROM_ISR()`
- [ ] `configPRIO_BITS` 与芯片 `__NVIC_PRIO_BITS` 一致
- [ ] 任务栈用 `uxTaskGetStackHighWaterMark` 验证过；开发期开 `configCHECK_FOR_STACK_OVERFLOW`

## 7. GPIO 特别项

- [ ] 复用号（【STM32/GD32】AF0-AF15；RP2040 等平台按其 GPIO 功能选择机制）对照数据手册复用表逐脚核对
- [ ] **调试引脚未被应用误配**（【STM32/GD32】PA13/PA14 = SWDIO/SWCLK；nRF 为专用 SWDIO/SWDCLK 引脚，其它平台按其调试口定义）——配错可能导致调试器无法连接；按型号尝试 Connect-Under-Reset（NRST 复位下连接）或该型号支持的恢复引导方式（见 ST AN4989/AN2606），能否走系统 bootloader 依器件与引脚复用而定
- [ ] I2C 引脚开漏 + 上拉；未用引脚按该芯片手册配置低功耗状态（【STM32/GD32】模拟输入）

## 8. 安全

- [ ] 【STM32/GD32】读保护（RDP）级别与部署阶段匹配；量产关调试口
- [ ] 看门狗已启用且喂狗路径无死区
- [ ] Flash 中无硬编码密钥；【STM32/GD32】敏感扇区考虑 PCROP

## 症状 → 常见原因 → 验证与修法（Top 16，按出现频率排序）

| 症状 | 常见原因 | 验证与修法 |
|---|---|---|
| 首次访问外设寄存器即出错/挂死 | 漏开外设时钟（表现依型号：总线错误/读零/写入无效） | 验证：核对 RCC 使能位；修法：时钟使能先于任何寄存器访问 |
| 外设完全无输出、引脚无波形 | 引脚复用/路由配置错误（【STM32/GD32】AF 复用号错） | 验证：数据手册/引脚复用表逐脚核对；修法：改正复用配置 |
| 串口打印乱码/收发异常 | 波特率用错总线时钟（【STM32/GD32】APB1/APB2 混淆）或时钟源宏定义不符 | 验证：打印实际外设时钟并与预期比对；修法：重算波特率分频、核对时钟源宏（【STM32/GD32】如 `-DHSE_VALUE`） |
| 串口完全无输出（printf 不打印） | printf 未重定向到该 UART（`fputc`/`_write`），或外设/GPIO 时钟未配 | 验证：检查重定向实现与初始化顺序；修法：补重定向、先配时钟 |
| 高频下随机 HardFault | Flash 等待周期不足 | 验证：HCLK 对照等待周期表；修法：升频**先增等待周期再切高频**，降频反向（按器件与供电电压核对） |
| DMA 传输静默失败/数据全 0 | 缓冲区在该平台不可 DMA 的内存（【STM32/GD32】CCM/DTCM） | 验证：链接脚本查看缓冲区所在段；修法：移入可 DMA 区域并按平台要求对齐 |
| 优化后 ISR 读到的总是旧值 | ISR 共享变量缺 volatile | 验证：反汇编确认读取被优化外提；修法：加 volatile，必要时加屏障 |
| SPI 完全不通 | CPOL/CPHA 与从机不符 | 验证：逻辑分析仪比对时钟相位；修法：按从机手册改模式 0~3 |
| 调用 FromISR 即硬错误 | ISR 优先级越过 FreeRTOS 边界，或宏表示方式用错 | 验证：核对 FreeRTOS port、配置阈值宏及 NVIC API 使用的优先级表示；修法：按同一表示方式将 ISR 放到允许调用 API 的优先级范围 |
| 一个外设的 DMA 无故失效 | DMA 通道/请求源冲突（【STM32/GD32】共用同一流） | 验证：列出全部 DMA 分配；修法：重映射或改轮询 |
| SWD 突然连不上芯片 | 调试引脚被应用重配（【STM32/GD32】PA13/PA14；nRF 为专用 SWDIO/SWDCLK） | 验证：检查最近 GPIO 配置改动；修法：Connect-Under-Reset 恢复（依型号），代码禁配调试引脚 |
| 程序在 ISR 里卡死 | ISR 内调 HAL_Delay | 验证：检查 ISR 调用链；修法：延时移出 ISR，用标志位+主循环 |
| 定时周期偏差大 | PSC/ARR off-by-one（都 +1 生效） | 验证：公式手算对照实际周期；修法：重算，核对定时器时钟倍频规则（【STM32/GD32】APB 定时器 ×2） |
| 一使能中断就立刻进 ISR | 未清 pending 就使能 | 验证：使能前读状态寄存器；修法：先清标志再 NVIC_EnableIRQ |
| 偶发数据错乱难复现 | ISR 与主循环读改写同一寄存器/变量 | 验证：梳理共享资源访问路径；修法：关中断临界区或原子操作 |
| 优先级行为与预期不符 | 优先级分组被多次设置 | 验证：搜索全部分组设置调用；修法：启动时设一次 |
