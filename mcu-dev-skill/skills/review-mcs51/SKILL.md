# 8051 (MCS-51) 评审清单

配合 `embedded-workflow` 阶段 4 使用。覆盖经典 51 与增强 51（STC8/STC15/N76 等）。逐类核查，分级 Critical / High / Medium，报告后重新生成完整修复代码。

## 1. 内存空间选型（51 特有，最高频翻车点）

- [ ] 变量空间与用途匹配：`data`(128B 直址，最快) / `idata`(256B 间址) / `pdata`(页外设) / `xdata`(扩展 RAM，最慢) / `code`(常量表必须 code)
- [ ] data/idata 总用量 < 128B/256B，且给栈留余量——**栈就在 idata 顶部**，变量挤占栈区 = 随机崩溃
- [ ] 增强型（STC8 系列）扩展 XRAM 需开启对应使能位（如 AUXR 的 EXTRAM 位）才能用满
- [ ] 大缓冲区/查表放 `xdata`/`code`，不放 data
- [ ] 内存模型（small/compact/large，Keil）或 SDCC 修饰与实际空间一致

## 2. 重入与调用安全（SDCC 关键坑）

- [ ] **SDCC 默认所有函数不可重入**——ISR 与主循环、或两层调用链调用同一函数 = 栈上参数/局部变量互相踩踏；共享函数加 `__reentrant` 或复制为两份
- [ ] ISR 内不调用任何不可重入且被主循环调用的函数（包括库函数 printf/memcpy 系列）
- [ ] ISR 与主循环共享变量加 `volatile` 并关注位操作的原子性（51 位操作对 data 位是原子的，对 xdata 不是）

## 3. 中断

- [ ] 中断向量号 = 8×编号 + 3（0x03/0x0B/0x13/0x1B…），SDCC `__interrupt(n)` 的 n 是向量编号，勿与 ARM 的 IRQ 号习惯混淆
- [ ] 每个使能的中断：外设使能位 + 对应 IE 位 + 总开关 EA，三层都开
- [ ] 优先级体系（IP/IPH 两级）设置符合需求；默认同优先级不互相抢占
- [ ] ISR 内清标志（有的外设读清、有的写 0 清，逐外设核对）
- [ ] ISR 短小：只置标志/搬单字节，耗时逻辑放主循环
- [ ] 多字节共享变量（16 位计数等）在 ISR 与主循环间访问的原子性处理（关中断窗口）

## 4. 时序与波特率

- [ ] **12T/6T/1T 分频模式**确认：STC 系列 1T 模式下定时器与波特率重装值与经典 12T 完全不同——按模式重算
- [ ] UART 波特率：定时器 1 方式 2 重装值按系统频率与模式重算，误差 <2%（用厂商工具或公式核对）
- [ ] 定时器初值 = 65536 − 计数（12T：再除 12），off-by-one 核对
- [ ] STC 的内部 IRC 频率设置与实际一致（出厂默认与编译假设不符会全线时序错）

## 5. SFR 与位定义

- [ ] SFR/sbit 地址逐个对照该型号数据手册（增强 51 的新 SFR 各型号差异大，不可凭经典 51 记忆）
- [ ] SDCC 语法 `__sfr __at(0x80) P0;` / `__sbit __at(0x90) P0_1;` 或头文件；与 Keil C51（`sfr P0 = 0x80;`）语法不混用
- [ ] Keil→SDCC 移植对照：`sbit`→`__sbit`、`interrupt(n)`→`__interrupt(n)`、`using`→`__using(n)`、data 存储类修饰加下划线
- [ ] 读写只读 SFR / 写保留位不做多余操作

## 6. 外设（增强 51）

- [ ] STC8 UART2 等"固定引脚/可切换引脚"外设的引脚切换位核对
- [ ] ADC/PWM/比较器使能顺序：先配置后上电，转换前等待稳定
- [ ] 端口准双向/推挽/开漏模式配置（STC 的 PxM0/PxM1）与外接电路匹配（I2C 必开漏）

## 7. 看门狗与低功耗

- [ ] 看门狗（STC WDT_CONTR/WKTCH）启用后喂狗路径覆盖所有长分支；喂狗窗口不越界
- [ ] 掉电/空闲模式唤醒源配置；掉电前关外设

## 8. 烧录（STC 冷启动 ISP 特有）

- [ ] STC-ISP/stcgal 只在上电复位的瞬间握手——**先点下载、再给板子上电**（冷启动流程），不是插着就能烧
- [ ] stcgal 参数：`-p` 端口、型号协议选择（stc8/stc15 系列 protocol 不同）
- [ ] USB 转串口（CH340，VID 0x1a86）驱动与端口确认；TX/RX 交叉接线核对
- [ ] ISP 监控区与用户程序区边界（擦除范围）确认

## 症状 → 原因 → 修法（Top 10）

| 症状 | 真正的原因 | 修法 |
|---|---|---|
| 偶发数据错乱、难复现 | ISR 调用了主循环也在调的函数（SDCC 不可重入） | 共享函数加 `__reentrant` 或复制两份 |
| 运行一段时间随机崩溃 | data/idata 变量挤占栈区 | 大变量挪 xdata，核对栈用量 |
| 串口乱码、定时差 12 倍 | 1T 芯片按 12T 公式计算 | 按 1T 重算波特率/定时初值 |
| 串口完全无输出 | TI 未置位就等发送、ES/EA 未开、printf/putchar 未重定向 | 发送前置位 TI；开 ES 与 EA；检查 putchar 重定向 |
| xdata 变量写入后读回丢失 | 扩展 RAM 使能位没开 | 开 AUXR.EXTRAM（按型号核对） |
| 跑飞或进错中断 | 中断向量号算错 | 向量地址 = 8n+3 逐个核对 |
| 中断不触发 | IE 三层（外设/IE 位/EA）漏一层 | 逐层检查使能位 |
| 控制的引脚不对 | sbit 位地址按字节地址直套 | 按位地址（0x80+位序）核对 |
| 烧录总是失败 | 先上电后点下载（顺序反了） | 先点下载、再冷启动上电 |
| I2C/输出带不动负载 | 端口未配模式，默认准双向弱驱动 | 配推挽/开漏（PxM0/PxM1） |
| 运行数分钟突然复位 | 看门狗喂狗窗口越界或漏喂 | 核对喂狗周期与窗口 |
