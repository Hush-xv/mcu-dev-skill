# 8051 (MCS-51) 评审清单

配合 `embedded-workflow` 阶段 4 使用。覆盖经典 51 与增强 51（STC8/STC15/N76 等）。逐类核查，分级 Critical / High / Medium，报告后默认输出**最小可应用 diff**；仅单文件示例或用户明确要求完整替换时才输出完整文件。

## 1. 内存空间选型（51 特有，最高频翻车点）

- [ ] 变量空间与用途匹配：`data`(128B 直址，最快) / `idata`(256B 间址) / `pdata`(页外设) / `xdata`(扩展 RAM，最慢) / `code`(常量表必须 code)
- [ ] 变量与栈不冲突：核对**该器件的存储器映射与链接/map 文件**（data/idata/xdata 实际容量与栈区位置依型号与内存模型而异），确认变量区、栈区与重入栈互不重叠
- [ ] 增强型 51 的扩展 XRAM 访问受使能位控制且**方向依型号而异**——检查 EXTRAM 状态并按该型号手册设定（如 STC8G：EXTRAM **清零**才是启用片内 XRAM，置 1 反而禁用）
- [ ] 大缓冲区/查表放 `xdata`/`code`，不放 data
- [ ] 内存模型（small/compact/large，Keil）或 SDCC 修饰与实际空间一致

## 2. 重入与调用安全（SDCC 关键坑）

- [ ] **SDCC 默认所有函数不可重入**（Keil C51 亦类似）——ISR 与主循环、或两层调用链调用同一函数 = 栈上参数/局部变量互相踩踏；解法以**该项目的编译选项、overlay 与调用图为准**：共享函数加 `__reentrant`、复制两份或调整调用结构
- [ ] ISR 内不调用任何不可重入且被主循环调用的函数——**库函数与编译器生成的算术辅助函数（乘除/浮点）同样有此风险**，以反汇编确认 ISR 实际调用链
- [ ] ISR 与主循环共享变量加 `volatile`；原子性**以反汇编结果为准**（C 表达式不必然生成单条位指令，多字节与读改写访问可能不原子）

## 3. 中断

- [ ] SDCC `__interrupt(n)` 的 n 是**中断编号**（0 起），不是向量地址——向量地址 = 0x0003 + 8×n（如 `__interrupt(0)` → 0x0003、`__interrupt(1)` → 0x000B）；勿与 ARM 的 IRQ 号习惯混淆
- [ ] 每个使能的中断：外设使能位 + 对应 IE 位 + 总开关 EA，三层都开
- [ ] 优先级体系（IP/IPH 两级）设置符合需求；默认同优先级不互相抢占
- [ ] ISR 内清标志（有的外设读清、有的写 0 清，逐外设核对）
- [ ] ISR 短小：只置标志/搬单字节，耗时逻辑放主循环
- [ ] 多字节共享变量（16 位计数等）在 ISR 与主循环间访问的原子性处理（关中断窗口）

## 4. 时序与波特率

- [ ] **12T/6T/1T 分频模式**确认：STC 系列 1T 模式下定时器与波特率重装值与经典 12T 完全不同——按模式重算
- [ ] UART 波特率：定时器 1 方式 2 重装值按系统频率与模式重算，误差 <2%（用厂商工具或公式核对）
- [ ] 定时器初值 = 65536 − 计数（12T：再除 12），off-by-one 核对
- [ ] STC 的内部 IRC 频率设置与实际一致（出厂默认与编译假设不符会全线时序错）

## 5. SFR 与位定义

- [ ] SFR/sbit 地址逐个对照该型号数据手册（增强 51 的新 SFR 各型号差异大，不可凭经典 51 记忆）
- [ ] SDCC 语法 `__sfr __at(0x80) P0;` / `__sbit __at(0x90) P0_1;` 或头文件；与 Keil C51（`sfr P0 = 0x80;`）语法不混用
- [ ] Keil→SDCC 移植对照：`sbit`→`__sbit`、`interrupt(n)`→`__interrupt(n)`、`using`→`__using(n)`、data 存储类修饰加下划线
- [ ] 读写只读 SFR / 写保留位不做多余操作

## 6. 外设（增强 51）

- [ ] STC8 UART2 等"固定引脚/可切换引脚"外设的引脚切换位核对
- [ ] ADC/PWM/比较器使能顺序：先配置后上电，转换前等待稳定
- [ ] 端口模式与外接电路匹配：STC 用 PxM0/PxM1（复位默认准双向），N76 用 PxM1/PxM2（复位默认输入高阻）——I2C 必开漏

## 7. 看门狗与低功耗

- [ ] 看门狗（STC WDT_CONTR/WKTCH）启用后喂狗路径覆盖所有长分支；喂狗窗口不越界
- [ ] 掉电/空闲模式唤醒源配置；掉电前关外设

## 8. 烧录（STC 冷启动 ISP 特有）

- [ ] STC-ISP/stcgal 只在上电复位的瞬间握手——**先点下载、再给板子上电**（冷启动流程），不是插着就能烧
- [ ] stcgal 参数：`-p` 端口、型号协议选择（stc8/stc15 系列 protocol 不同）
- [ ] USB 转串口（CH340，VID 0x1a86）驱动与端口确认；TX/RX 交叉接线核对
- [ ] ISP 监控区与用户程序区边界（擦除范围）确认

## 症状 → 常见原因 → 验证与修法（Top 11）

| 症状 | 常见原因 | 验证与修法 |
|---|---|---|
| 偶发数据错乱、难复现 | ISR 调用了主循环也在调的函数（SDCC 不可重入） | 验证：反汇编确认 ISR 调用链；修法：加 `__reentrant`/复制两份/调整调用结构 |
| 运行一段时间随机崩溃 | data/idata 变量挤占栈区 | 验证：map 文件核对变量区与栈边界；修法：大变量挪 xdata |
| 串口乱码、定时差 12 倍 | 1T 芯片按 12T 公式计算 | 验证：确认芯片 1T/6T/12T 模式；修法：按实际模式重算波特率/初值 |
| 串口完全无输出 | TI 未置位就等发送、ES/EA 未开、printf/putchar 未重定向 | 验证：读 TCON/IE 寄存器确认；修法：发送前置位 TI，开 ES 与 EA，检查 putchar 重定向 |
| xdata 变量写入后读回丢失 | 扩展 RAM 使能位方向设错 | 验证：读回使能位状态；修法：按该型号手册设定（如 STC8G：EXTRAM 清零启用片内 XRAM） |
| 跑飞或进错中断 | 中断向量号算错 | 验证：向量地址 = 8n+3 逐个核对；修法：改正编号 |
| 中断不触发 | IE 三层（外设/IE 位/EA）漏一层 | 验证：读寄存器逐层确认；修法：三层全开 |
| 控制的引脚不对 | sbit 位地址计算错误 | 验证：对照芯片手册位地址表——通用规则仅适用于**可位寻址 SFR**（字节地址为 8 的倍数，0x80~0xF8）：位地址 = 其字节地址 + 位序，如 P1(0x90) 为 0x90~0x97；修法：改正位地址 |
| 烧录总是失败 | 先上电后点下载（顺序反了） | 验证：复现操作顺序；修法：先点下载、再冷启动上电 |
| I2C/输出带不动负载 | 端口模式与负载/外接电路不匹配 | 验证：按厂商读模式寄存器（STC：PxM0/PxM1，复位默认准双向；N76：PxM1/PxM2，复位默认输入高阻）；修法：按负载配置推挽/开漏 |
| 运行数分钟突然复位 | 看门狗喂狗窗口越界或漏喂 | 验证：测量最长主循环周期；修法：调整喂狗周期与窗口 |
